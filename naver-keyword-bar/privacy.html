검색량 가로바 — 개인정보처리방침

최종 수정일: 2026년 11월 27일 · 적용 버전: 1.1.0 이상

「검색량 가로바」(Chrome 확장 프로그램, 이하 "확장")는 이용자의 개인정보를 소중히 다루며, 아래와 같이 처리 방침을 밝힙니다. 이 확장은 네이버(주)와 무관한 비공식 도구입니다.

1. 수집·이용하는 정보

확장은 다음 정보만 취급합니다.

정보취급 방식
네이버 검색광고 API 키 3종
(Customer ID · API Key · Secret Key)		 이용자가 확장 팝업에서 직접 입력한 값. 이용자의 크롬 계정 동기화 저장소(chrome.storage.sync)에만 저장되며, 검색량 조회 시 네이버 검색광고 API로 전송됩니다.
카드 접기/펼치기 상태 같은 동기화 저장소에 저장되는 화면 설정값(개인 식별 정보 아님).
검색어 이용자가 네이버에 이미 입력한 값으로, 현재 페이지 주소에서 읽어 화면에 표시하고 검색량 조회에 사용할 뿐 저장하지 않습니다.

확장은 위 정보 외에 이름·이메일·전화번호·주소·위치·방문 기록·검색 기록·쿠키 등을 수집하지 않습니다.

2. 보관 위치와 보관 기간

  • API 키와 화면 설정은 이용자의 브라우저 저장소(크롬 계정 동기화 저장소)에만 보관됩니다. 개발자는 이 값에 접근할 수 없습니다.
  • 보관 기간은 이용자가 직접 지우거나 확장을 삭제할 때까지입니다. 팝업에서 키를 새로 저장하면 이전 값은 덮어써지고, 확장을 삭제하면 저장된 값도 함께 삭제됩니다.
  • 검색량 조회 결과는 확장의 메모리에만 30분간 임시 보관되며, 브라우저를 닫거나 확장이 다시 시작되면 사라집니다. 디스크에 저장하지 않습니다.

3. 전송과 제3자 제공

  • API 키와 검색어는 검색량 조회를 위해서만 네이버 검색광고 API(https://api.searchad.naver.com)와 네이버 자동완성(https://ac.search.naver.com)으로 전송됩니다. 두 요청 모두 이용자의 브라우저에서 네이버로 직접 나가며, 개발자의 서버나 중간 서버를 거치지 않습니다.
  • 개발자는 이용자의 정보를 수집·열람·저장하지 않으며, 제3자에게 판매·공유·이전하지 않습니다. 광고나 프로파일링에 사용하지 않습니다.
  • 전송 구간은 모두 HTTPS로 암호화됩니다.

4. 이용자의 권리

  • 팝업에서 API 키를 새 값으로 바꾸거나 지울 수 있습니다.
  • 확장을 삭제하면 저장된 모든 값(동기화 저장소 포함)이 삭제됩니다.
  • 크롬의 '계정 동기화' 설정에서 동기화를 끄면 값은 해당 기기에만 보관됩니다.

5. 아동의 개인정보

확장은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 별도로 수집하지 않습니다.

6. 방침의 변경

이 방침이 바뀌면 이 페이지에 변경 내용과 시행일을 함께 게시합니다. 중요한 변경이 있는 경우 확장 업데이트 안내에 함께 표시합니다.

English summary

Search Volume Bar — Privacy Policy (last updated 2026-11-27)

  • What we handle: the NAVER Search Ad API credentials you type into the popup (Customer ID, API Key, Secret Key) and the card's collapsed state. Both are stored only in your own chrome.storage.sync, so they follow your Chrome profile; the developer cannot read them.
  • Where it goes: your credentials and the search query are sent only to api.searchad.naver.com and ac.search.naver.com to fetch search volumes, directly from your browser over HTTPS. There is no developer server.
  • No collection, no sharing: the developer does not collect, store, sell, or share your data, and does not use it for advertising or profiling. Search results are cached in memory for 30 minutes and never written to disk.
  • Your control: you can overwrite or clear the keys in the popup, and uninstalling the extension deletes all stored values.
